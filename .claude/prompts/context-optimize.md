# 프롬프트: 컨텍스트·비용 최적화

> 토큰 소비를 줄이는 체크리스트와 컨텍스트 관리 루틴.

---

## 세션 시작 전 체크리스트

- [ ] CLAUDE.md 라우팅 표 확인 → 필요한 파일만 읽을 경로 파악
- [ ] 이번 작업에 필요한 MCP 서버만 활성화
- [ ] 모델 선택: 작업 난이도에 맞게 (→ `model-select.md` 참조)
- [ ] 이전 세션에서 이어가는 경우 `claude --continue` 사용 (캐시 유지)

---

## 컨텍스트 관리 루틴

### 50% 도달 시
```
/compact Focus on [현재 작업명], drop [완료된 탐색 과정, 읽은 파일 내용]
```

### 70% 도달 시 (반드시 실행)
- 옵션 A: `/compact` → 압축 후 이어서
- 옵션 B: `/clear` → 초기화 후 새로 시작 (독립적인 새 작업일 때)

## 프롬프트 캐싱 극대화

- 캐시 TTL: 5분
- 세션을 끊지 않고 이어가면 입력 비용 90% 절감
- 2분 간격으로 작업하면 캐시 사실상 항상 유지
- `claude -c` (또는 `claude --continue`)로 이전 세션 이어가기

## CLAUDE.md 최적화 기준

- **200줄·1,000토큰 이내** 유지
- 각 줄마다 자문: "이 줄이 없으면 Claude가 실수하는가?"
  - Yes → 유지
  - No → 삭제
- 코드에서 읽을 수 있는 내용 (파일 구조, 패키지명 등) → CLAUDE.md에 쓰지 말 것

## MCP 서버 관리

| 상태 | 기준 | 조치 |
|------|------|------|
| 활성 | 매주 1회 이상 사용 | 유지 |
| 검토 | 1~2주 미사용 | 필요성 재확인 |
| 비활성화 | 2주 이상 미사용 | `.mcp.json`에서 제거 |

- 서버 1개 = 메시지당 100~8,000토큰
- 5개 조합 = 최대 20,000토큰 (짧은 작업 전체 비용을 상회할 수 있음)
