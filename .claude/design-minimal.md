# 디자인 최소 버전

> 3개 필드만 채우면 Claude가 동작합니다. 상세 버전은 `design.md`.
> 프로젝트 초기에는 이 파일만, 브랜드 정립 후 `design.md`로 확장.

---

## 필수 3가지

```
Primary 색상:  #[색상코드]     (예: #5B5BD6)
본문 폰트:     [폰트명]        (예: Pretendard)
어조:         [톤]            (예: 친근하고 직접적 / 전문적이고 간결)
```

---

## 이것만 채우면 Claude가 자동으로 결정하는 것

- 보조 색상 → Primary 기반 파생 색상 자동 선택
- 폰트 크기·굵기 → 일반적인 타이포 스케일 (H1 48px, 본문 16px 등)
- 여백·radius → 4의 배수 시스템 기본값
- 대비율 → WCAG AA 기준 4.5:1 자동 준수
